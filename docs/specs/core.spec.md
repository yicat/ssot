# 内核：数据单元与校验（底座）

## 目的

定义整个系统最基础的数据单元——**断言**——以及它的校验规则。其余底座都建立在它之上：
`admission.spec.md` 管它怎么进来，`verification.spec.md` 管它凭什么可信，
`basicdata.spec.md` 管它怎么被用。

解决的问题：同一份事实会有多个来源、多个版本、多种表述，且持续被修改。
若把它当成「某个对象的某个字段值」，会立刻丢失来源、时效与成立条件，
于是无法判断可信度、无法呈现冲突、无法追踪过期——而这三件事恰恰是「不能错」的全部内容。

## 术语

- **断言（Assertion）**：最小的事实单位。它不是「对象的属性」，而是**一句话**：
  某个主体、在特定条件下、由某个来源、在某个时间点、以某个分级成立。
- **主体（subject）**：断言谈论的对象，用**稳定标识**而非名称指代。
- **谓词（predicate）**：属性名或关系名。**必须来自一个齐备可用的数据定义**
  （见 `dataschema.spec.md`）。
- **限定条件（qualifiers）**：使该断言成立的条件——适用版本或时间区间、触发条件等。
- **来源（source）**：谁说的。
- **依据（evidence）**：凭什么这么说。**与来源不是一回事**（见 `verification.spec.md`）。
- **溯源（provenance）**：文档标识 + 段落锚点 + 修订标识 + 采集时间。**只能指一处。**
- **分级（confidence）**：L1 直引 / L2 结构化 / L3 推导 / L4 推断。
- **量纲**：同一事实在不同来源中的表示单位（百分数 vs 小数）。
- **穷尽性**：可枚举集合的完整性。

## 领域规则（Given-When-Then）

### 断言的基本结构

- Given 任何内容进入系统 When 存储 Then 必须以断言形式存储，
  携带主体、谓词、取值、限定条件、来源、溯源与分级
- Given 一条断言缺少来源或溯源 When 存储 Then **拒绝**
- Given 两条断言主体与谓词相同但**限定条件不同** When 存储 Then **并存**，互不覆盖
- Given 两条断言主体、谓词与限定条件完全相同但取值不同 When 存储 Then
  并存并**标记冲突**，不得择一

> 这一条是本规格的核心。它直接回答「同一个说法在不同条件下有不同效果」——
> 那**不是指代问题**，是条件被错建模成了对象的属性。

### 取值与四态

- Given 一条断言 When 记录 Then 它的取值处于四态之一：有值 / 未知 / 空值 / 缺失
  （定义与约束见 `dataschema.spec.md`）
- Given 一个值为「未知」 When 校验必填 Then **通过**，但**不计为已填充**
- Given 一个值为「未知」 When 生成答案 Then 必须标注
- Given 四态并存 When 统计 Then 必须能分别计数

### 主体标识

- Given 一个主体 When 被引用 Then 必须使用**稳定标识**，不得使用名称
- Given 一个主体有多个称呼 When 记录 Then 走**词表**的机制登记
  （词面、来历、条件指代，见 `dict.spec.md`）——本规格不再另设一套别名表
- Given 一个名称指向多个主体 When 被引用 Then **登记为歧义**并按
  `decision.spec.md` 处置，不得猜测
- Given 一个主体标识 When 与另一类主体的标识相同 Then 允许——
  身份在各自的定义范围内唯一，不全局唯一

### 分级

- Given 原文照抄的内容 When 记录 Then 分级为 **L1**，且必须能通过与原文比对**自动验证**
- Given 从文本解析成字段的内容 When 记录 Then 分级为 **L2**；
  **回退解析**（原文没有明确格式、靠猜格式读到的）**不得为 L1**
- Given 由其他内容计算得出的内容 When 记录 Then 分级为 **L3**，且必须记录**推导链**；
  **仅在上下文中立时固化**，否则只作为 Case 的中间结果（见 `derivation.spec.md`）
- Given 凭理解补全的假设 When 记录 Then 必须分级为 **L4**，且**不得与 L1 混同展示**
- Given 一条 L4 断言 When 被答案引用 Then 答案必须标注其中存在推断成分
- Given 一条断言 When 记录 Then 分级**不得超过**其解析方式允许的上限
  （上限来自数据定义的抽取规则，见 `dataschema.spec.md`）

> 分级的意义：**隐式信息与直引事实必须可分辨**。
> 没有分级，猜测会与事实混在一起，无从追溯。

### 溯源

- Given 一条断言 When 记录 Then 必须携带文档标识、段落锚点与采集时间
- Given 一条断言的溯源 When 阅读 Then **只能指一处**——
  指多处的话「这个值从哪读出来的」就没有唯一答案
- Given 来源内容的修订标识发生变化 When 检测到 Then 由该来源产出的断言
  标为**依据已变**（不再叫「待重核验」——没有队列可排，标注才是能起作用的东西）
- Given 原文被删除或不可达 When 查询溯源 Then 标注**依据不可达**，
  **不得静默丢弃锚点**
- Given 一条断言由公式算出 When 记录 Then 它没有原文锚点，
  依据是推导链而非文档段落

### 校验

- Given 一条记录 When 校验 Then 六类各自独立判定：
  **必填、类型、范围、枚举、唯一、引用完整性**
- Given 任一校验失败 When 写入 Then 持久化层**零变更**
- Given 一批记录部分失败 When 写入 Then 处理方式（整批回滚 / 逐条报告）
  由**调用方选择**，默认整批回滚
- Given 引用目标不存在 When 校验 Then 失败并指出引用目标
- Given 校验所依赖的定义尚未加载 When 校验 Then **失败并要求补齐**，不得放行
- Given 一条数据取值不在枚举集合内 When 校验 Then **接受并标记「未建模取值」**，
  不得拒绝也不得静默通过（开放性规则见 `dataschema.spec.md`）

> 注意这里的严格程度是**不对称**的：对定义里我们自己写的东西严（未知类型名即拒），
> 对数据里别人给的东西宽但不静默。

### 量纲归一

- Given 同一事实来自两个来源且量纲不同 When 比对 Then **必须先归一**
- Given 两个来源归一后仍不一致 When 检测 Then 标记冲突，不得择一
- Given 一条断言未声明量纲 When 与其他断言比对 Then **拒绝比对**并指出缺失的声明
- Given 缺少两个单位之间的换算关系 When 比对 Then 拒绝并指出缺失的单位对

> 实测依据：同一式神的暴击在来源 A 记为 `50`、来源 B 记为 `0.5`；
> 若不归一，会把**一致**误判为**冲突**。

### 穷尽性与归因

- Given 可枚举集合存在多个来源（索引 / 属性表 / 明细文件） When 校验 Then
  逐一对齐并报告差异
- Given 出现仅存在于一侧的条目 When 报告 Then 必须**逐一归因**，
  判定是缺失还是合法类别差异
- Given 归因结论为合法类别差异 When 记录 Then 记录该类别，后续同类不再报警

> 实测依据：索引声明 275 个角色而明细文件有 281 个，多出的 6 个是**主角而非式神**。
> **报警 ≠ 判错，必须能归因**；否则真实问题会被误报淹没。

### 原子性与并发

- Given 并发写入同一唯一约束 When 提交 Then 只有一个成功，
  另一个得到冲突错误而非静默覆盖
- Given 事务回滚 When 查询 Then 无任何残留
- Given 一次变更集 When 应用 Then **原子**：失败全回滚，不留半应用状态

## 验收标准

- [ ] 断言必须携带主体、谓词、取值、限定条件、来源、溯源、分级，缺任一项即拒绝
- [ ] 限定条件不同的两条断言并存，互不覆盖
- [ ] 主体、谓词、限定条件全同而取值不同的两条断言并存且被标记冲突
- [ ] 取值的四态可区分且可分别计数
- [ ] 「未知」值满足必填但不计为已填充
- [ ] 主体引用使用稳定标识而非名称
- [ ] 称呼的登记走词表机制，不另设别名表
- [ ] 一个名称指向多个主体时登记为歧义，不猜测
- [ ] L1 可与原文自动比对验证
- [ ] 回退解析读出的值分级不为 L1
- [ ] 分级不超过其解析方式允许的上限
- [ ] L4 断言在输出中与 L1 可区分
- [ ] 一条断言的溯源只指一处
- [ ] 源内容修订标识变化后，相关内容标为「依据已变」
- [ ] 原文不可达时锚点保留并标注
- [ ] 公式算出的断言没有原文锚点，依据为推导链
- [ ] 六类校验各有正反用例且各自独立判定
- [ ] 校验失败时持久化层零变更
- [ ] 依赖缺失时校验失败而非放行
- [ ] 枚举未建模取值被接受并标记
- [ ] 量纲不同的两源比对前先归一
- [ ] 未声明量纲的断言拒绝参与比对
- [ ] 缺换算关系时拒绝比对并指出单位对
- [ ] 穷尽性差异逐一归因；记为合法类别差异后不再重复报警
- [ ] 并发写同一唯一约束只有一个成功
- [ ] 回滚后无残留
- [ ] 变更集应用原子，失败全回滚

## 边界与异常

- 空定义文件、语法错误、非 UTF-8：加载失败并报出位置
- 主体标识重复但指向不同记录：拒绝并报冲突
- 断言取值超长、数值溢出：拒绝，**不得截断或回绕**
- 溯源锚点在原文变更后越界：标记锚点失效，**保留断言本身**
- 同一断言被两个来源在同一时刻以不同取值给出：并存并标记冲突
- 批量为空：合法，但不产生任何变更
- 校验所依赖的定义尚未加载：失败，不前移
- 定义的循环引用：**待定**
- 断言的限定条件互相排斥（不可能同时成立）：允许存入，
  但引用它的答案必须报出冲突约束
- 一条断言的谓词在定义变更后不存在：保留但标为「定义已变」，
  不再参与计算，并提示需重新抽取

## 前后端契约

本底座不直接对外暴露接口，它的形状体现在各部件服务的返回类型里。已确定的约束：

- 断言的分级、来源、溯源与核验记录必须可被**外部读取**，而不只显示在界面上
- 校验结果必须**逐条可定位**：哪一条、哪个字段、哪一类约束
- 冲突必须成对暴露（双方的取值与来源），不得只给一个「冲突」标记
- 四态必须在序列化中可区分：`"unknown"` 与 `null` 与缺字段是三件不同的事
