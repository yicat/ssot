# 接入层：取回、存档、解析

## 目的

把外部内容**取回来并存档**，产出候选。

接入层是系统与外部世界的边界。它**只负责"拿到"与"看懂格式"**，
**不判断内容是否为事实、不决定可信度、不写事实源**。

它存在的意义有三条：

1. **隔离外部的不确定性**——源会改版、会限流、会加反爬。这些变化不应波及准入规则。
2. **原样存档**——存档之后，准入层可以**离线重放**，不必重新抓取。
3. **保持事实源的唯一入口**——接入层无法直接写库，因此校验不可能被绕过。

## 术语

- **源（source）**：一个外部内容提供者。
- **通道（channel）**：访问某个源的具体方式。同一个源可以有多个通道
  （例如 API、镜像、浏览器），通道可替换。
- **修订标识（revision）**：源内容的版本标记，用于判断是否变化。
- **原件（artifact）**：取回的原始内容，**原样保存**。
- **候选（candidate）**：解析原件得到的中间产物——一个值、它在原文中的位置、以及解析方式。
  候选**不是断言**，它还没有经过准入。
- **重放（replay）**：用已存档的原件重新走解析与准入，不重新抓取。

## 领域规则（Given-When-Then）

### 取回

- Given 一次同步 When 完成 Then 必须记录每个单元的修订标识与采集时间
- Given 某个源需要非标准通道（例如需浏览器通过人机校验） When 同步 Then
  该通道属于接入层，且必须**可配置替换**——更换通道不得影响解析与准入规则
- Given 同步失败 When 处理 Then **不得降级为写入部分或不完整的内容**；
  应记录失败并保留上一次成功的内容
- Given 请求被限流或失败 When 重试 Then 必须退避，不得加剧对方压力
- Given 同步进行中 When 中断 Then 不得留下半成品原件

### 存档

- Given 任何取回的内容 When 落盘 Then **必须原样存档**，且与解析结果**分开保存**
- Given 一份原件 When 存档 Then 必须记录：源、通道、修订标识、采集时间
- Given 原件已存档 When 需要重新处理 Then 必须能**离线重放**，不得要求重新抓取
- Given 同一修订标识的原件 When 再次取回 Then 不重复存档（幂等）

### 解析

- Given 一份原件 When 解析 Then 产出候选：值、命中位置、解析方式
- Given 解析使用了回退或推测策略 When 产出候选 Then 必须**标记解析方式**，供准入层据此定级
- Given 解析失败 When 处理 Then 产出「解析失败」候选并**保留原文位置**，不得丢弃
- Given 原件格式无法识别 When 解析 Then 整体标记为不可解析并报告，**不得猜**

### 增量

- Given 某单元的修订标识发生变化 When 同步 Then 只重新处理变化的单元
- Given 修订标识未变 When 同步 Then 不产生候选
- Given 某单元在源中消失 When 同步 Then 记录消失事实，**不得直接删除**对应数据
  （删除决定属于准入层）

### 职责边界

- Given 接入层的产出 When 交付 Then 只包含原件与候选，**不含任何可信度判断**
- Given 接入层 When 运行 Then **不得**直接写入事实源
- Given 准入规则发生变更 When 应用 Then 接入层不需要改动

## 验收标准

- [ ] 每次同步记录修订标识与采集时间
- [ ] 更换通道不影响解析与准入规则
- [ ] 同步失败时不产生部分或不完整内容，且上次成功内容保持可用
- [ ] 重试带退避，不产生突发压力
- [ ] 原件原样存档，与解析结果分开保存
- [ ] 原件带源、通道、修订标识、采集时间
- [ ] 已存档原件可离线重放，无需重新抓取
- [ ] 相同修订标识不重复存档
- [ ] 候选携带命中位置与解析方式
- [ ] 回退解析产生的候选被标记
- [ ] 解析失败时保留原文位置并产出失败候选，不丢弃
- [ ] 无法识别的格式被整体标记，不猜测
- [ ] 修订标识未变时不产生候选
- [ ] 单元从源中消失时记录消失事实，不直接删除数据
- [ ] 接入层产出中不含可信度判断
- [ ] 接入层无法写入事实源

## 边界与异常

- 网络不可达、通道不可用：记录失败，保留上次内容，**不产生任何候选**
- 源返回错误页或人机校验页：**不得当作内容解析**，须识别并报错
- 原件编码非 UTF-8：尝试识别编码后存档；无法识别则标记失败
- 原件超大：允许分段存档，但必须保持可完整重放
- 同一单元在一次同步中被取回两次且内容不同：保留两份，标记异常
- 修订标识缺失：允许存档，但标记该源不支持增量，只能全量比对
- 解析器版本变化：必须记录版本，使重放结果可解释
- 源被永久关闭：允许保留全部历史原件与候选，不受影响

## 前后端契约

**待定**，取决于对外接口形态。已确定的约束：

- 同步状态（成功/失败/部分失败）必须可被外部查询
- 原件与候选必须可被外部读取，以支持重放与人工核验
- 通道配置必须可在不重新编译的前提下更换

## 待确认

1. 原件存档的保留策略（是否需要永久保留以支持任意时点重放）
2. 通道的配置形式
3. 增量的粒度：按页面 / 按命名空间 / 按修订标识范围
4. 解析器是否需要独立的版本与核验状态
5. 是否支持多个源同时接入同一实体（当前设计上支持，但冲突处理在准入层）

## 附：与准入层的分工实例

以本项目实测的 wiki 抓取为例：

| 事项 | 归属 |
|---|---|
| 启动浏览器通过人机校验 | 接入 |
| 调用 MediaWiki API | 接入 |
| 分批抓取、退避重试 | 接入 |
| 原样存档页面内容（含修订标识） | 接入 |
| 从 wikitext 解析出字段值 | 接入 |
| 标记「此处用了回退解析」 | 接入 |
| 判断解析结果是否为事实 | **准入** |
| schema 校验 | **准入** |
| 断言分级（L1–L4） | **准入** |
| 与既有断言冲突检测 | **准入** |
| 来源登记与别名登记 | **准入** |
| 赋初始核验状态 | **准入** |
| 发现修订标识变化 | 接入 |
| 决定哪些断言转为待重核验 | **准入** |

注意最后两行：**接入层"发现"变化，准入层"决定"影响面。** 这是两层边界的一个典型例子。
