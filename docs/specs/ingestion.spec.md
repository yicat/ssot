# 接入：存档与解析（底座）

## 目的

把外部内容**原样存下来**，并**看懂它的格式**，产出候选。

在旧结构里这一层还负责取回；现在**取回是工具的活**（见 `tools.spec.md`）——
工具是 Agent 的手脚，可自由组合，也正因为如此它不被信任。
本层接在工具之后，做两件工具不做的事：

1. **原样存档**。存档之后，准入可以**离线重放**，不必重新取数。
2. **解析并标记解析方式**。回退解析读出来的值必须带着「我是猜格式读到的」这个标记，
   否则准入无法据此压低它的分级。

边界一句话：**本层只负责「拿到并看懂格式」，不判断内容是否为事实、
不决定可信度、不写事实源。** 工具发现变化，本层看懂变化，准入决定影响面。

## 术语

- **源（source）**：一个外部内容提供者。
- **通道（channel）**：访问某个源的具体方式（接口、镜像、浏览器）。
  **通道属于工具**，必须可替换——换通道不得影响解析与准入规则。
- **修订标识（revision）**：源内容的版本标记，用于判断是否变化。
- **原件（artifact）**：取回的原始内容，**原样保存**，与解析结果分开存。
- **候选（candidate）**：解析原件得到的中间产物——一个值、它在原文中的位置、
  以及**解析方式**。候选**不是事实**，它还没有经过准入。
- **重放（replay）**：用已存档的原件重新走解析与准入，不重新取数。

## 领域规则（Given-When-Then）

### 存档

- Given 工具取回的内容 When 交付 Then **必须原样存档**，
  且与解析结果**分开保存**
- Given 一份原件 When 存档 Then 必须记录：源、通道、修订标识、采集时间
- Given 原件已存档 When 需要重新处理 Then 必须能**离线重放**，不得要求重新取数
- Given 同一修订标识的原件 When 再次取回 Then 不重复存档（幂等）
- Given 同步进行中 When 中断 Then **不得留下半成品原件**——
  半个文件比没有文件更糟，因为它看起来像一份完整的原件
- Given 原件编码非 UTF-8 When 存档 Then 尝试识别编码；
  识别不了则标记失败，**不得按错误编码硬解**

### 解析

- Given 一份原件 When 解析 Then 产出候选：取值、命中位置、**解析方式**
- Given 解析使用了回退或推测策略 When 产出候选 Then 必须**标记解析方式**，
  供准入据此压低分级——**回退解析不得被当作直引**
- Given 解析失败 When 处理 Then 产出「解析失败」候选并**保留原文位置**，不得丢弃
- Given 原件格式无法识别 When 解析 Then 整体标记为不可解析并报告，**不得猜**
- Given 源返回的是错误页或人机校验页 When 解析 Then **不得当作内容解析**，
  必须识别出来并报错——把错误页解析成数据是最坏的一种静默
- Given 解析器版本变化 When 执行 Then 必须记录版本，使重放结果可解释

### 增量

- Given 某单元的修订标识发生变化 When 同步 Then 只重新处理变化的单元
- Given 修订标识未变 When 同步 Then **不产生候选**
- Given 某单元在源中消失 When 同步 Then **记录消失事实**，
  **不得直接删除**对应数据——删除的决定属于准入与人
- Given 修订标识缺失 When 存档 Then 允许，但标记该源不支持增量，只能全量比对
- Given 同一单元在一次同步中被取回两次且内容不同 When 处理 Then
  保留两份并标记异常，不静默取其一

### 职责边界

- Given 本层的产出 When 交付 Then 只包含原件与候选，**不含任何可信度判断**
- Given 本层 When 运行 Then **不得**直接写入事实源
- Given 准入规则发生变更 When 应用 Then 本层不需要改动
- Given 本层 When 展示进展 Then 说明「取回了什么、解析出多少候选」，
  **不说明「有多少是对的」**——那不是它的事

### 与工具的分工

- Given 一次取数 When 发生 Then **取回、退避重试、通道切换**属于工具
- Given 取回的内容 When 交付 Then **原样存档、解析、标记解析方式**属于本层
- Given 工具不可用 When 处理 Then 本层可以处理**已有的原件**（重放），
  不需要工具在场——这是存档带来的能力
- Given 一份内容来自人手工导入（不是工具） When 处理 Then 走同一条路：
  存档 → 解析 → 候选

## 验收标准

- [ ] 取回的内容原样存档，与解析结果分开保存
- [ ] 原件带源、通道、修订标识、采集时间
- [ ] 已存档原件可离线重放，无需重新取数
- [ ] 相同修订标识不重复存档
- [ ] 中断不留半成品原件
- [ ] 非 UTF-8 原件尝试识别编码，识别不了时标记失败而不硬解
- [ ] 候选携带命中位置与解析方式
- [ ] 回退解析产生的候选被标记
- [ ] 解析失败时保留原文位置并产出失败候选，不丢弃
- [ ] 无法识别的格式被整体标记，不猜测
- [ ] 错误页与人机校验页被识别为错误，不被当作内容解析
- [ ] 解析器版本被记录
- [ ] 修订标识未变时不产生候选
- [ ] 单元从源中消失时记录消失事实，不直接删除数据
- [ ] 修订标识缺失时标记该源不支持增量
- [ ] 同一单元一次同步中被取回两次且内容不同时保留两份并标记异常
- [ ] 本层产出中不含可信度判断
- [ ] 本层无法写入事实源
- [ ] 准入规则变更不需要本层改动
- [ ] 本层的进展报告不包含「有多少是对的」
- [ ] 通道与重试属于工具，本层不承担
- [ ] 本层可以只靠已存档原件工作（工具不在场时）

## 边界与异常

- 网络不可达、通道不可用（由工具上报）：记录失败，保留上次内容，
  **不产生任何候选**
- 原件超大：允许分段存档，但必须保持可完整重放
- 同一原件的两次存档内容相同：幂等，不重复存
- 原件被外部删除：标注「原件不可达」，已解析出的候选不受影响，
  但重放不可用并说明
- 源被永久关闭：允许保留全部历史原件与候选，不受影响
- 解析规则改进后重放得出不同候选：保留两次结果并说明是规则变更导致
- 原件格式是已知格式但内容损坏：产出失败候选并保留位置，不整体丢弃
- 项目没有任何原件（还没取过数）：允许；界面说明「还没有取过数」并给出取数入口

## 前后端契约

本层不单独设界面；它通过工具与文档的接口体现。已确定的约束：

- 同步状态（成功 / 失败 / 部分失败）必须可被外部查询
- 原件与候选必须可被外部读取，以支持重放与人工判断
- 通道配置属于工具，必须可在不重新编译的前提下更换
- 一份原件的解析结果必须能回答「用了哪个解析器版本、哪些位置是回退解析」

## 待确认

1. 原件存档的保留策略（是否需要永久保留以支持任意时点重放）
2. 增量的粒度：按页面 / 按命名空间 / 按修订标识范围
3. 解析器是否需要独立的版本与状态
4. 「消失事实」的登记形态：属于文档、属于变更叙事，还是单独的记录
5. 是否允许同一原件被多套解析规则各解析一次（当前：不允许多份候选并存）

## 附：与工具、准入的分工实例

以本项目实测的 wiki 抓取为例：

| 事项 | 归属 |
|---|---|
| 启动浏览器通过人机校验 | **工具** |
| 调用 MediaWiki API | **工具** |
| 分批抓取、退避重试、通道切换 | **工具** |
| 原样存档页面内容（含修订标识） | **接入** |
| 从 wikitext 解析出字段值 | **接入** |
| 标记「此处用了回退解析」 | **接入** |
| 识别错误页 / 人机校验页并报错 | **接入** |
| 判断解析结果是否为事实 | **准入** |
| 定义校验（类型、约束、量纲、定义是否齐备） | **准入** |
| 分级（L1–L4） | **准入** |
| 与既有事实的冲突检测 | **准入** |
| 来源登记与指代登记 | **准入** |
| 赋初始状态 | **准入** |
| 发现修订标识变化 | **接入** |
| 决定哪些引用标为「依据已变」 | **准入 + 文档** |

注意最后两行：**接入「发现」变化，准入「决定」影响面。**

还有一个可能反直觉的归属：**工具取回的东西不能直接进准入**。
工具的产出先进存档，再由接入解析成候选。这样「哪次取数产生了什么」
永远查得到，而工具本身不必被信任。
