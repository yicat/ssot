# docs/notes/ —— 调研与实测记录

这里放**过程性材料**：调研、实测数字、踩过的坑。

| 放哪 | 权威性 |
|---|---|
| `docs/specs/` | 我们确认过的约定（**权威**，改代码前先改它） |
| `docs/notes/`（本目录） | 调研与实测记录：**不是规范**，可能过期，随时会被推翻 |

规矩：

1. 写清**日期与结论**，以及**怎么验的**（命令、样本、对拍参照）——只写结论的笔记过几个月就没用了。
2. 与 spec 冲突时以 spec 为准；笔记里的结论要升格成约定，得搬进 `docs/specs/`。
3. 记「什么时候**不该**用这个结论」，别只记好处。
