# 核验：主张有没有出处，出处支不支持它

## 什么时候用

- 用户说「验一下这篇」「这条说法靠谱吗」「出处对不对」
- 一篇整理稿要从 draft 变 published 之前，人想先看证据
- 有个数字/结论在几篇文档里说法不一致

## 怎么核

对整理稿里**每一条会被当成事实的主张**，走一遍：

1. `doc_read` 读整理稿，把主张一条条列出来（一条主张一行，别合并）。
2. 每条主张去看它后面跟的双链：`link_resolve` 解析 `[[raw/…#^块]]`，
   看命中的**是哪一行原文**（`blockLine` / `blockText`）。没有双链的 → 直接记「**无出处**」。
3. `doc_read` 读那段原文，判断三种情况之一：
   - **支持**：原文确实这么说（把原文那一句抄进证据里）
   - **部分支持**：原文说的是 A，整理稿写成了 A′（把差别说清，这是最常出问题的一类）
   - **不支持 / 无出处**：原文没说，或说的相反
4. 数字、日期、专有名词逐个对：`table_query` 查数据表交叉验证（表里的数是**原始数据**，
   比正文里的二手转述可信）。
5. 结论按「主张 → 证据（原文行号 + 原文）→ 判定」列成一张清单交回。
   **不要在清单里下"可以发布"的结论**——那是人的判断。

## 不许做

- **不许改 `status`**：核验的产出是证据，不是批准。发布只能由人做。
- **不许替原文说话**：找不到支持就说找不到；「大概意思是这样的」不算证据。
- 默认**不改文档**。确实需要在正文留痕时，只能在末尾追加一节「核验记录」
  （写清核验时间、依据、未通过项），并且仍不能动 `status`。
